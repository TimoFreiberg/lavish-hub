# Working on lavish-kit

Last verified: 2026-11-13

Run `just test` for the Node and browser suites. They need `lavish-axi` and
Playwright's cached Chromium. Run `just test-e2e` explicitly inside herdr for
real delivery and terminal placement. It creates and cleans up its own scratch
terminals and space. Do not send to, relabel, close, or kill other terminals.

Use jj. Start with an empty change, review `jj diff --git`, and commit only
files you changed. Use imperative commit messages of at most 72 characters,
without a trailing period. Preserve the repo-local noreply author identity.
Leave the working-copy change empty after committing. Do not push or move
bookmarks without the operator's approval.

This is a public repo. Keep private names, work details, credentials, hostnames,
and absolute home paths out of code, tests, and docs. Use `$HOME`/XDG paths in
examples. Never read or print secrets to inspect an environment or config.
Keep macOS and Linux working. Lockfiles are generated by npm, not hand-edited.

The relay's outbox, receipt targets, and launch checkpoints prevent recovery
from redirecting a save or launching a second terminal. Preserve those
contracts when changing delivery. Generated pages and relay data stay local
and outside the reviewed repository.
