# Working on lavish-kit

Last verified: 2026-11-13

Run `just test` for the Node and browser suites, never two at once in one
checkout. They need `lavish-axi` and Playwright's cached Chromium. Run
`just test-e2e` separately, inside herdr, to check real delivery and terminal
placement. It creates and cleans up its own scratch terminals and space. Do not
send to, relabel, close, or kill other terminals.

Use jj. Start with an empty change, review `jj diff --git`, and commit only
files you changed. Use imperative commit messages of at most 72 characters,
without a trailing period. Preserve the repo-local noreply author identity.
Leave the working-copy change empty after committing. Do not push or move
bookmarks without the operator's approval.

This is a public repo. Keep private names, work details, credentials, hostnames,
and absolute home paths out of code, tests, and docs. Use `$HOME`/XDG paths in
examples. Never read or print secrets to inspect an environment or config.
Keep macOS and Linux working. Lockfiles are generated by npm, not hand-edited.

Each received save or action keeps the target it arrived with
(`src/relay.mjs`), and Create PR records its launch attempt before calling
herdr (`src/pr-action.mjs`). That stops crash recovery from saving to a
different file or opening a second Create PR terminal. Keep both properties
when changing delivery. Generated pages and worker files stay local and outside
the reviewed repository.
