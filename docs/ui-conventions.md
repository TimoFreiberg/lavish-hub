# UI conventions

UI code lives in `web/` and `src/hub-*.mjs`. See [hub.md](hub.md) for the workspace workflow, [feedback-routing.md](feedback-routing.md#delivery-guarantees) for save and action target guarantees, and [TESTING.md](../TESTING.md#just-shots) for visual checks. Existing deviations noted below are potential follow-up candidates, so ask the user before changing unrelated UI.

## Interaction and editing

- Turn Lavish annotation mode off on entry for views meant for direct interaction or custom editing (`setAnnotationMode(false)`), keep the reviewer's manual toggle choice across refreshes, and restore `setAnnotationMode(true)` when leaving (`modeView` in `web/hub-app.mjs`). Known gap: `startsInExplore` covers `Diff` today, leaving `Tasks` in annotation mode.
- Put `data-lavish-action` only on non-native or shadow-hosted widgets that must handle pointers while annotation mode is on (`.viewport` and `.draft` in `web/diff-app.mjs`, `dialog` in `web/confirm-navigation.js`, `#lavish-hub-sidebar` in `src/hub-html.mjs`), and on individual matched hub deep-link anchors (`web/hub-app.mjs`, `src/hub-html.mjs`) so they remain clickable in annotation mode. Do not place `data-lavish-action` on `#view` itself, or turning annotations back on cannot target view content.
- Show rendered or read-only content by default, with an icon-only pencil button (`editButton` / `.commit-edit` in `web/hub-app.mjs` and `web/hub.css`, matching `aria-label` and `title`). On `Tasks` and published Markdown, `.commit-edit` sits top-right inside `.commit-description-wrap` and swaps to the `<textarea>` editor while focusing it. In the `Diff` commit rail, `.rail-row .commit-edit` sits in its own trailing grid column, opens the description editor above the diff (`.commit-editor-drawer`), and toggles `.is-editing` on that button (`.rail-row .commit-edit.is-editing`). Exceptions: immutable and divergent commits hide `.commit-edit`, published HTML has no source editor, and inline queued diff comment pencils (`.diff-comment-card`) open the Lavish sidebar queue editor.
- Pair Save and Cancel controls, bind `Escape` in hub `<textarea>` editors to Cancel if `!state.saving`, and disable Save, Cancel, `.commit-edit`, and task checkboxes while a save is in flight (`web/hub-app.mjs`). Hub `<textarea>` fields stay editable during a save (closing only if `state.text` still matches the submitted text), whereas queueing an inline diff comment disables Queue and Cancel and sets `textarea.readOnly = true` (`web/diff-app.mjs`, `Meta+Enter` with `aria-keyshortcuts="Meta+Enter"`). `Tasks` autosaves checkboxes on `change` (`data-task-line` in `web/document-controls.mjs`), while published Markdown checkboxes do not autosave.

## Layout, sizing, and scrolling

- Size single-text-box containers down to short content rather than reserving tall empty boxes (`textarea.commit-editor` in `web/hub.css`, `.diff-comment-card`). Known gaps: base `textarea` (`8rem` in `web/hub.css`), `.draft textarea` (`88px` in `web/diff.css`), and `#editor` (`65vh` in `web/document.css`).
- Fill available viewport width and height on full-page views (`flex: 1`, `min-height: 0`) rather than using fixed-height boxes. Standalone `mountDiff` (`web/diff.css`), desktop `.hub-diff` (`Diff` in `web/hub.css`), and published HTML sibling pages do this, whereas narrow-viewport `.hub-diff` and the fixture-only `.published-document` iframe in `web/hub.css` still use `75vh` (`min-height: 30rem`).
- Keep the hub sidebar (`.hub-sidebar` in `web/hub-app.mjs` and `#lavish-hub-sidebar` on sibling HTML pages in `src/hub-html.mjs`) and the commit rail (`.commit-rail` in `web/hub-app.mjs`) collapsible and resizable via `attachResizablePane` and `createSafeStorage` (`web/hub-lifecycle.js`). Reconcile `.rail-row` nodes in place so range selection, `.rail-body-preview` toggles, and the description editor above the diff (`.commit-editor-drawer`) preserve `.commit-rail-scroll` scroll position. Opening `.commit-editor-drawer` temporarily narrows the diff to that commit and restores the previous range (and row button focus with `{ preventScroll: true }`) on close unless the reviewer changes the range manually.
- In the hub `Diff` view (`hideSidebar: true, collapsedByDefault: true` in `web/hub-app.mjs` and `web/diff-app.mjs`), hide `mountDiff`'s file-tree sidebar and start files collapsed. Clicking a file header, pressing `c`, clicking Expand all, or following a file deep link adds the path to `state.expanded`, keeping expanded files open across range changes while present.
- Keep `@pierre/diffs` `CodeView` inside its bounded scroll element (`.viewport`) and render `.file-header` at exact `HEADER_HEIGHT` (`44px` in `web/diff-app.mjs` and `web/diff.css`) so virtualized file offsets do not drift.
- Bound and scroll regions that can grow long (`overflow: auto` or `overflow-x: auto`), such as desktop `.commit-rail-scroll` and `.commit-editor-drawer` (`45vh` cap in `web/hub.css`), standalone diff `.file-tree` and `.commits pre` (`web/diff.css`), inline diff comment cards (`.diff-comment-card`), and wide Markdown tables and `<pre>` blocks (`web/document.css`). Keep `wrap="off"` on `textarea.commit-editor` so commit line breaks stay visible while editing. Assign pane `scrollTop` (`.file-tree.scrollTop` in `web/diff-app.mjs`, and `.commit-rail-scroll.scrollTop` when scrollable in `web/hub-app.mjs`) instead of calling `scrollIntoView()` so Lavish's outer document does not scroll. Intentional exception: `textarea.tasks-editor` grows to `scrollHeight` (`max-height: none`) so the task list scrolls with the page.

## Drafts, navigation, and focus

- Retain user drafts and original save targets across errors, conflicts, and polling, re-checking draft cleanliness after async reads resolve (`web/hub-app.mjs`, [feedback-routing.md](feedback-routing.md#delivery-guarantees)). Failed `Tasks` checkbox saves open the source editor with the draft, and dirty diff drafts hold incoming patches in `state.pending`.
- Preserve `drafts` in memory across view switches inside `hub.html`. Open tabs do not follow remote selections. Publications and selections for other views show a bottom-right toast (`data-lavish-action`, `role="status"`, `aria-live="polite"`) with Open and dismiss buttons. Plain `publish` does not change `selected`. Unread documents keep a cyan sidebar badge (`aria-hidden="true"`, with `aria-describedby`, `title`, and `data-unseen`) until acknowledged. Use `window.lavish?.setDocumentMeta?.({ title })` to keep the browser tab title at `<title> · Lavish` (or `<repo> · Lavish` when untitled) across view switches (`applyNavBadge` and `formatTabTitle` in `web/hub-lifecycle.js`). Guard browser reloads (`beforeunload`) and page-leaving navigation between `hub.html` and published HTML sibling pages (`confirmDraftNavigation` in `web/confirm-navigation.js`, `createLeaveGuard` in `web/hub-lifecycle.js`).
- Group collapsed published documents in `<details class="nav-older">` (hidden when empty) on hub and sibling sidebars, with `.nav-collapse-toggle` as a sibling of the button or link inside `.nav-row` rather than nested inside it (omitted when a document lacks a `version`, `web/hub-app.mjs`, `src/hub-html.mjs`). Keep the active document in the main list across polls if it started there until navigating away or hiding it manually. Open `.nav-older` when the active document enters it, close it when the active document leaves unless the user opened `.nav-older` on that page, preserve user toggles across polls (`createOlderDisclosureController` in `web/hub-lifecycle.js`), and move focus to `<summary>` when a focused row control moves into a closed `.nav-older`.
- Keep the top-level window as the sole history owner: use `window.lavish.syncUrl` for view and fragment changes, and handle `lavish:urlChange` for Back/Forward. Use `window.lavish.navigateFrame` for cross-document navigation inside Lavish (falling back to `location.replace` outside it via `createLeaveGuard` in `web/hub-lifecycle.js`) so replacing the iframe keeps browser history from restoring an old document before the current page's draft guard runs. Replace iframe hashes rather than adding history entries, and handle authored fragment links in bubble phase after checking `defaultPrevented` so annotation mode can intercept them.
- On published HTML sibling pages, show a green reload button on the active sidebar row when an update waits on authored edits (replacing the `New` badge on that row). Keep `.nav-reload` beside the link in `.nav-row`, never inside it. Use `--ob-green` and `--ob-on-accent`, flash the row once per version unless `prefers-reduced-motion: reduce` is set, and reload directly on click (`src/hub-html.mjs`). Auto-reloads wait out a short debounce after `[data-lavish-ui]` input so Lavish persists annotation drafts first, and reverting edits or resetting a form applies the pending update when navigation guards permit.
- Give inputs in `#view` unique, stable `aria-label` values so `refresh()` restores focus and caret selection, pass `{ preventScroll: true }` if focusing inside scroll panes, and restore focus to the trigger if `confirmDraftNavigation` cancels.
- Keep one refresh scheduler per page: stop it while the tab is hidden, catch up when it becomes visible, keep that state separate from navigation pauses, draft guards, and annotation mode, and request the repository snapshot only on `Diff`, asking for a current one when `Diff` is entered (`needsSnapshot` and `refresh` in `web/hub-app.mjs` and the inline sidebar script in `src/hub-html.mjs`). A page that loads hidden keeps its first poll so it has content when shown, a queued automatic catch-up stays a plain poll while a manual or post-save refresh keeps its force, and re-entering `Diff` over a previous snapshot shows `Refreshing repository snapshot…` on the full-stack range bar.

## Accessibility, styling, and sandbox

- Briefly highlight deep-linked commit rows (`.rail-row`) and file headers (`.file-header`) with `.deep-link-highlight` (`web/hub.css`, `web/diff.css`), using a static tint instead of animation when `prefers-reduced-motion: reduce` is set. Line targets in `Diff` use a temporary line selection instead (`web/diff-app.mjs`).
- On `/hubs` (`vendor/lavish/src/hub-dashboard.js`), group hubs alphabetically by repository, keeping each group in startup order, and list unread artifacts in sidebar order as cyan-accented `?view=ID` links. Wrap more than four unread artifacts in a focusable, labeled scroll region (`.unread-list-box`), preserve scroll position and focus across refreshes, and pause polling while the tab is hidden (refreshing when visible again).
- Satisfy `axe-core` and geometry checks (`scripts/visual/checks.mjs`): set `aria-label` on icon buttons (`aria-hidden="true"` on decorative SVGs), patch open shadow-root controls missing labels or keyboard activation (`[data-utility-button]` in `web/diff-app.mjs`), put `tabindex="0"` and `role="region"` with `aria-label` on non-interactive scroll containers (`src/markdown-accessibility.mjs`), set `aria-current` on active nav items, avoid horizontal page overflow or unellipsized text clipping, and render repository text via `textContent` or HTML escaping.
- Use Orangebox `--ob-*` tokens (`src/orangebox.mjs`), passing `CodeView` Shadow DOM overrides via `unsafeCSS` `:host`. In `hub.html` (`src/hub-runtime.mjs`), unscoped element selectors in `web/hub.css` match inside `@scope (.hub-diff)` and `@scope (.hub-markdown)`, whereas `:root`, `html`, `body`, and `#app` inside `diff.css` and `document.css` do not match. On sibling HTML pages (`src/hub-html.mjs`), apply `data-theme="orangebox"` only if `<html>` lacks `data-theme`, insert `<base href>` when absent while resolving relative bases against the resource URL and preserving absolute external bases, and reserve left root padding for `#lavish-hub-sidebar` without wrapping `<body>` children.
- Account for Lavish's opaque-origin `#artifact` sandbox (`self.origin === "null"`, no `allow-same-origin`): wrap `localStorage` in `try/catch` with an in-memory fallback, load Web Workers from `Blob` URLs (`LAVISH_HUB_WORKER_SOURCE`) with a main-thread fallback (`web/diff-app.mjs`), and post browser actions to `${config.url}/action` with `x-lavish-capability` on the proxied UI address rather than loopback ports.
