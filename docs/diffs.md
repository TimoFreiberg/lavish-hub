# Diff

The workspace hub's Diff view shows the tracked commit stack beside the full stack diff or a selected commit or range, and supports line feedback pinned to what is displayed. Expand a file header to view its hunks, and use the controls between hunks to reveal unchanged lines from the displayed commit or range (pinned to the snapshot's jj operation). Expansion loads each side on demand for modified, renamed, or copied regular UTF-8 text files, up to 1 MiB per side. A read that has not answered within ten seconds is abandoned. When a file or an older snapshot is unavailable, the original diff stays visible, the hub reports the failed expansion, and expanding again retries the read. A non-empty comment draft holds incoming diff updates behind a `Diff changed.` notice whose **Refresh** button unlocks once you queue or cancel the draft, and queued comments reappear inline whenever their range is displayed.

See [hub](hub.md) for the workspace workflow and [workflow gaps](hub-gaps.md) for removed standalone diff capabilities.
