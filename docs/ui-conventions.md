# UI conventions

UI code lives in `web/` and `src/hub-*.mjs`. See [hub.md](hub.md) for the workspace workflow, [feedback-routing.md](feedback-routing.md#delivery-guarantees) for save and action target guarantees, and [TESTING.md](../TESTING.md#just-shots) for visual checks. Existing deviations noted below are potential follow-up candidates, so ask the user before changing unrelated UI.

## Interaction and editing

- Turn Lavish annotation mode off on entry for views meant for direct interaction or custom editing (`setAnnotationMode(false)`), keep the reviewer's manual toggle choice across refreshes, and restore `setAnnotationMode(true)` when leaving (`modeView` in `web/hub-app.mjs`). Known gap: `startsInExplore` covers `Commits` and `Changes` today, leaving `Tasks` in annotation mode.
- Put `data-lavish-action` only on non-native or shadow-hosted widgets that must handle pointers while annotation mode is on (`.viewport` and `.draft` in `web/diff-app.mjs`, `dialog` in `web/confirm-navigation.js`, `#lavish-hub-sidebar` in `src/hub-runtime.mjs`). Do not place `data-lavish-action` on `#view` itself, or turning annotations back on cannot target view content.
- Show rendered or read-only content by default, with a top-right icon-only pencil button (`editButton` / `.commit-edit` in `web/hub-app.mjs` and `web/hub.css`, matching `aria-label` and `title`) that swaps to the editor and focuses the `<textarea>`, reserving right padding so the button cannot overlap text. Exceptions: immutable and divergent commits hide `.commit-edit`, published HTML has no source editor, and inline queued diff comment pencils (`.diff-comment-card`) open the Lavish sidebar queue editor.
- Pair Save and Cancel controls, bind `Escape` in hub `<textarea>` editors to Cancel if `!state.saving`, and disable Save, Cancel, `.commit-edit`, and task checkboxes while a save is in flight (`web/hub-app.mjs`). Hub `<textarea>` fields stay editable during a save (closing only if `state.text` still matches the submitted text), whereas queueing an inline diff comment disables Queue and Cancel and sets `textarea.readOnly = true` (`web/diff-app.mjs`, `Meta+Enter` with `aria-keyshortcuts="Meta+Enter"`). `Tasks` autosaves checkboxes on `change` (`data-task-line` in `web/document-controls.mjs`), while published Markdown checkboxes do not autosave.

## Layout, sizing, and scrolling

- Size single-text-box containers down to short content rather than reserving tall empty boxes (`textarea.commit-editor` in `web/hub.css`, `.diff-comment-card`). Known gaps: base `textarea` (`8rem` in `web/hub.css`), `.draft textarea` (`88px` in `web/diff.css`), and `#editor` (`65vh` in `web/document.css`).
- Fill available viewport width and height on full-page views (`flex: 1`, `min-height: 0`) rather than using fixed-height boxes. Standalone `mountDiff` (`web/diff.css`), desktop `.hub-diff` (`Changes` in `web/hub.css`), and published HTML sibling pages do this, whereas narrow-viewport `.hub-diff` and the fixture-only `.published-document` iframe in `web/hub.css` still use `75vh` (`min-height: 30rem`).
- Keep `@pierre/diffs` `CodeView` inside its bounded scroll element (`.viewport`) and render `.file-header` at exact `HEADER_HEIGHT` (`44px` in `web/diff-app.mjs` and `web/diff.css`) so virtualized file offsets do not drift.
- Bound and scroll regions that can grow long (`overflow: auto`), such as commit descriptions (unwrapped x-axis scroll to preserve line breaks), diff-stat lists, inline diff comment cards, and wide Markdown blocks, enabling `resize: vertical` on read-only blocks only if overflowing (`web/hub-app.mjs`). Assign diff `.file-tree.scrollTop` instead of calling `scrollIntoView()` so Lavish's outer document does not scroll (`web/diff-app.mjs`). Intentional exception: `textarea.tasks-editor` grows to `scrollHeight` (`max-height: none`) so the task list scrolls with the page.

## Drafts, navigation, and focus

- Retain user drafts and original save targets across errors, conflicts, and polling, re-checking draft cleanliness after async reads resolve (`web/hub-app.mjs`, [feedback-routing.md](feedback-routing.md#delivery-guarantees)). Failed `Tasks` checkbox saves open the source editor with the draft, and dirty diff drafts hold incoming patches in `state.pending`.
- Preserve `drafts` in memory across view switches inside `hub.html`, including remote switches (`lavish-kit hub --view` or `publish`) to same-page views. Guard browser reloads (`beforeunload`) and page-leaving navigation between `hub.html` and published HTML sibling pages (`confirmDraftNavigation` in `web/confirm-navigation.js`): on `hub.html`, remote switches pause only if leaving for a published HTML sibling page with unsaved drafts (`web/hub-app.mjs`), while edited sibling pages pause remote switches away (`src/hub-runtime.mjs`).
- Give inputs in `#view` unique, stable `aria-label` values so `refresh()` restores focus and caret selection, pass `{ preventScroll: true }` if focusing inside scroll panes, and restore focus to the trigger if `confirmDraftNavigation` cancels.
- Keep one refresh scheduler per page: stop it while the tab is hidden, catch up when it becomes visible, keep that state separate from navigation pauses, draft guards, and annotation mode, and request the working-copy snapshot only from views that render it, asking for a current one when such a view is entered (`needsSnapshot` and `refresh` in `web/hub-app.mjs`; the inline sidebar script in `src/hub-runtime.mjs`). A page that loads hidden keeps its first poll so it has content when shown, a queued automatic catch-up stays a plain poll while a manual or post-save refresh keeps its force, and a view re-entered over a previous snapshot says that snapshot is refreshing.

## Accessibility, styling, and sandbox

- Satisfy `axe-core` and geometry checks (`scripts/visual/checks.mjs`): set `aria-label` on icon buttons (`aria-hidden="true"` on decorative SVGs), patch open shadow-root controls missing labels or keyboard activation (`[data-utility-button]` in `web/diff-app.mjs`), put `tabindex="0"` and `role="region"` with `aria-label` on non-interactive scroll containers (`src/markdown-accessibility.mjs`), set `aria-current` on active nav items, avoid horizontal page overflow or unellipsized text clipping, and render repository text via `textContent` or HTML escaping.
- Use Orangebox `--ob-*` tokens (`src/orangebox.mjs`), passing `CodeView` Shadow DOM overrides via `unsafeCSS` `:host`. In `hub.html` (`src/hub-runtime.mjs`), unscoped element selectors in `web/hub.css` match inside `@scope (.hub-diff)` and `@scope (.hub-markdown)`, whereas `:root`, `html`, `body`, and `#app` inside `diff.css` and `document.css` do not match. On sibling HTML pages (`src/hub-html.mjs`), apply `data-theme="orangebox"` only if `<html>` lacks `data-theme`, insert `<base href>` when absent while resolving relative bases against the resource URL and preserving absolute external bases, and reserve left root padding for `#lavish-hub-sidebar` without wrapping `<body>` children.
- Account for Lavish's opaque-origin `#artifact` sandbox (`self.origin === "null"`, no `allow-same-origin`): wrap `localStorage` in `try/catch` with an in-memory fallback, load Web Workers from `Blob` URLs (`LAVISH_KIT_WORKER_SOURCE`) with a main-thread fallback (`web/diff-app.mjs`), and post browser actions to `${config.url}/action` with `x-lavish-capability` on the proxied UI address rather than loopback ports.
